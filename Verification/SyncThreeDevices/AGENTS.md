- .NET MAUI 10

## Objetivo
Adaptar las interfaces existentes a los diseños
de Figma sin alterar innecesariamente la lógica.

## Reglas de trabajo
1. Inspeccionar el código antes de modificarlo.
2. Conservar los eventos, bindings y navegación.
3. No eliminar funcionalidades existentes.
4. Evitar duplicar componentes.
5. Reutilizar estilos y controles.
6. Adaptar las interfaces a Windows y Android.
7. Trabajar una interfaz a la vez.
8. Explicar qué archivos se modificarán.
9. Verificar la compilación después de cambios.
10. No modificar la base de datos sin autorización.
